# Baibai — online virtual temple demo

`baibai.hk` — 拜拜 線上虛擬廟宇 Demo (static site, v34).

- Static, no build step, no server, no secrets. Entry point: `index.html`.
- Assets live under `assets/` (Heart Sutra chant audio, logo badge, three.js).
- Public version was v26; this repo deploys v33 (v30 bigger garden + faster walking, v31 lake lotus/flowers/dragonflies/butterflies/koi, v32 entry wording, v33: incense — 3 sticks per visit + smoke only after offering + burner sized to the figure; leaving the hall goes straight back to the courtyard; map doubled, lake enlarged, pond life random, taller trees and mountains, temple pushed back for depth, hall seats widened, entry page logo cleaned up, temple plaque stays Chinese in every language; v34: the visitor is re-skinned as a little Taoist acolyte （道童） — dark-blue robe, pale-gold sash, topknot, chubbier head — with a boy/girl acolyte picker on the entry screen; the designed 道童 art is used as the picker portraits and as the sweeping acolyte who greets you in the garden).
- Deployed on Vercel (project `baibai`) with custom domains `baibai.hk` and `www.baibai.hk`.
